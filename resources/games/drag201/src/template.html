    Cara main

    1. Tahan GAS saat lampu kuning. Jaga jarum di zona hijau.
    2. Lampu HIJAU → tap OPER (lepas kopling). Kecepatan reaksi = RT.
    3. Jarum masuk hijau → tap OPER lagi untuk naik gigi. Pas = PERFECT.
    4. NOS 🔥 sekali per balapan. Start sebelum hijau = diskualifikasi.
    5. Garasi: modif mesin, knalpot, gir, ban + cat & striping. Pemula? Beli Matic CVT, tanpa oper gigi.

    Keyboard: Spasi tahan = GAS (sebelum start) · K/Enter = START & oper gigi · N = NOS · start sebelum hijau = diskualifikasi, ulang · Duel P2: A gas · S oper · D NOS
