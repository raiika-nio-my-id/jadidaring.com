# Langit Bersama (game in git)

Shared drawing sky, sibling of Drawquarium (same net/rules/codec, forked 2026-10-30).
Served at https://jadidaring.com/game/langitbersama inside the site layout (main nav + game frame).
See `docs/games-in-git.md` for the pattern.

- **Draw & fly**: 5 kinds (kite, bird, balloon, paper plane, cloud) over a dashed guide.
- **Shared global wind** and a shared 60x time-of-day sky clock (`?jam=18.5[&hari=N][&jalan]` override).
- `?wallpaper` = sky-only fullscreen. Storage keys `langitbersama.*`, session name key `jdng.langitbersama`.
- GM: `?gmjd` opens the typed-code modal: POST rooms/{code}/gamemaster (admin session only). The old shared key is retired.
- Player name follows the Jadidaring account (`window.__JD_ME`): the gate keeps avatar/language, the name field is read-only; guests are "Tamu" (saving needs login). Old `langitbersama.name` nicknames are ignored.
- Player data (rooms, kites, chat, residents, scores) lives in the database and is reached through
  `/game/langitbersama/api/game/*`. Nothing in this folder stores player data.

## Files

| Path | What |
|---|---|
| `src/template.html` | Page skeleton with `/*CONFIG*/ /*CSS*/ /*SNIPPETS*/ /*RULES*/ /*NET*/ /*APP*/` markers |
| `src/style.css` | All game CSS |
| `src/app.js` | Game (sky, draw, chat, walkers) |
| `src/net.js` | Platform client for `/api/game/*` (rewritten to `/game/langitbersama/api/game/*` at serve time) |
| `src/rules.js` | Shared state rules (cleaners, caps) |
| `src/config.json` | Tunables + 9 language strings |
| `build.cjs` | Inlines `src/*` into `game.html` (ASCII-only) |
| `game.html` | Built, served file. Commit it together with `src/` |

## Build / deploy

```
node resources/games/langitbersama/build.cjs
env -u ADMIN_API_SECRET php vendor/bin/phpunit tests/Feature/GitGamesTest.php
git commit -am "Langit Bersama: ..." && git push   # push to main deploys
```

No admin PATCH any more: the `html` column of the database profile is kept only as the rollback copy.
Rollback: set `GIT_GAMES=` (empty) in the server `.env`, or revert the commit, and `/game/langitbersama`
serves the old database HTML again.
