    Cara main

    1. Lampu hijau → ketuk ON. Pas di hijau = start kilat. Sebelum hijau = curi start (+1 dtk).
    2. Tiap mendekati tikungan, jarum di bar bawah masuk zona. Ketuk TIKUNG di emas = PAS, hijau = oke.
    3. Telat / kecepetan = terpental. Kalau mobil terlalu kencang: course out, terbang keluar lintasan!
    4. Garasi: dinamo (kencang vs torsi), roller (lebar jendela tikungan), ban (cocokkan dengan lintasan).
    5. 3 lap. Jembatan lane changer memutar jalur tiap lap, jadi adil.

    Keyboard: Spasi / Enter = ON & TIKUNG · M = suara
